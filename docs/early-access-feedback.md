# نموذج ملاحظات تجربة مستقبلي 100

شكراً لمساعدتك في تحسين التطبيق. لا تكتب اسمك الكامل أو رقم هاتفك أو أي كلمة مرور أو معلومات شخصية حساسة.

## معلومات اختيارية
- نوع الجهاز والمتصفح:
- هل هذه أول مرة تستخدم فيها التطبيق؟ نعم / لا
- الصفحة أو الميزة التي جرّبتها:

## تجربة الاستخدام
1. هل استطعت العثور على الدرس المطلوب؟ نعم / لا
2. هل فتح الدرس بشكل صحيح؟ نعم / لا
3. هل استطعت إكمال الاختبار ورؤية النتيجة؟ نعم / لا
4. هل بقي تقدمك بعد إعادة تحميل الصفحة؟ نعم / لا / لم أختبر
5. هل واجهت زرّاً لا يعمل أو صفحة فارغة؟ اذكر الخطوات لإعادة المشكلة:
6. هل وجدت خطأً في معلومة أو إجابة؟ اذكر اسم الدرس والسؤال والمصدر إن توفر:
7. ما أكثر شيء أعجبك؟
8. ما أهم شيء ينبغي تحسينه أولاً؟
9. هل ترغب في تجربة نسخة أحدث؟ نعم / لا

## إرشادات للمراجعة
- أرسل وصف المشكلة فقط، ولا ترفق معلومات شخصية.
- ميّز بين الخطأ التقني والخطأ المحتمل في محتوى المنهج.
- لا تعتبر السؤال وزارياً موثّقاً إلا عند وجود مصدر يمكن التحقق منه.
