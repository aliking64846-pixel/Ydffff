# مستقبلي 100 — اجتماعيات ثالث متوسط

منصة ويب تعليمية عربية موجهة للموبايل، مبنية على كتاب الاجتماعيات للثالث المتوسط.

## بنية المشروع

- `index.html` — هيكل الصفحة ونقاط تحميل الملفات.
- `assets/css/app.css` — التصميم والتنسيقات المتجاوبة.
- `assets/js/navigation.js` — التنقل بين صفحات التطبيق.
- `assets/js/runtime.js` — تسجيل أخطاء التشغيل.
- `assets/js/app.js` — واجهة التطبيق، بيانات الدروس والاختبارات.
- `assets/js/ministerial-bank.js` — بنك الأسئلة الوزارية.
- `assets/js/learning-engine.js` — سجل الأخطاء والتكرار الذكي.
- `assets/js/study-content.js` — بناء محتوى الدرس من ملفات الكتاب.
- `book-*.txt` — ملفات نص الكتاب؛ تبقى في جذر المشروع لأن محرك المحتوى يحمّلها من مسارات الجذر.
- `.github/workflows/site-check.yml` — يفحص صياغة JavaScript ووجود الملفات وبيانات الدروس آلياً.

## محتوى المنصة

- 62 درساً موزعة على الجغرافية والتاريخ والتربية الوطنية والاجتماعية.
- واجهة RTL متجاوبة مع الهاتف.
- تقدم محلي على الجهاز عبر `localStorage`.
- أسئلة وزارية ومراجعة، وسجل أخطاء وتكرار ذكي.
- خطة دراسة وتحليل أداء ومحاكاة اختبار.
