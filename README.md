# مستقبلي 100 — اجتماعيات ثالث متوسط

منصة ويب تعليمية عربية موجهة للموبايل، مبنية على كتاب الاجتماعيات للثالث المتوسط المرفوع في المحادثة.

## الموجود في النسخة الأولى
- 62 درساً موزعة على الجغرافية والتاريخ والتربية الوطنية والاجتماعية.
- واجهة RTL متجاوبة مع الهاتف.
- بحث وتصنيف حسب المادة.
- تقدم محلي على الجهاز عبر localStorage.
- أسئلة ومراجعة بصيغة وزارية.
- سجل للأخطاء والتكرار الذكي.
- صفحة «طريقك إلى 100/100».
- ملف واحد مستقل: index.html، مناسب لـ GitHub Pages.
