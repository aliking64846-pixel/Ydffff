# مستقبلي 100 — منصة تعليمية عراقية

منصة ويب تعليمية عربية موجهة للموبايل. تبدأ باجتماعيات الثالث المتوسط، مع خطة للتوسع التدريجي إلى مواد ومراحل أخرى بعد اختبار جودة المحتوى وتجربة الطلاب.

## الميزات الحالية
- 62 درساً موزعة على الجغرافية والتاريخ والتربية الوطنية والاجتماعية.
- واجهة RTL متجاوبة مع الهاتف.
- حفظ التقدم محلياً على الجهاز عبر localStorage.
- اختبارات، سجل أخطاء، مراجعة ذكية، وخطة دراسة.
- بنك أسئلة وزارية يفصل الأسئلة الموثقة عن أسئلة التدريب.
- فحوص آلية عبر GitHub Actions للتحقق من ملفات المشروع وصياغة JavaScript وسلامة مصادر الأسئلة.

## بنية المشروع
- index.html — هيكل الصفحة ونقاط تحميل الملفات.
- assets/css/app.css — التصميم والتنسيقات المتجاوبة.
- assets/js/navigation.js — التنقل بين صفحات التطبيق.
- assets/js/runtime.js — تسجيل أخطاء التشغيل.
- assets/js/app.js — واجهة التطبيق وبيانات الدروس والاختبارات.
- assets/js/ministerial-bank.js — بنك الأسئلة الوزارية.
- assets/js/learning-engine.js — سجل الأخطاء والتكرار الذكي.
- assets/js/study-content.js — بناء محتوى الدرس.
- book-*.txt — ملفات نص الكتاب المستخدمة من محرك المحتوى.
- .github/workflows/site-check.yml — فحوص آلية لسلامة الملفات والبيانات.

## النشر عبر GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages.
3. من Build and deployment اختر Deploy from a branch.
4. اختر الفرع main والمجلد /(root)، ثم Save.
5. تحقق من ظهور الموقع فعلياً قبل مشاركة الرابط.

الرابط المتوقع للموقع:
https://aliking64846-pixel.github.io/Ydffff/

قد يتطلب نشر GitHub Pages تفعيل الإعدادات أو الانتظار حتى يكتمل النشر. إذا لم يفتح الرابط، راجع Settings → Pages وحالة النشر.

## ملاحظات الجودة والخصوصية
- التقدم الحالي محلي على الجهاز؛ لا تفترض أنه ينتقل تلقائياً بين الأجهزة.
- يجب اختبار الميزات على هاتف حقيقي قبل اعتبار الإصدار جاهزاً.
- راجع المحتوى الدراسي ومصادره وحقوق استخدامه قبل التوسع إلى مواد جديدة.
- اجمع أقل قدر ممكن من بيانات الطلاب، ولا تطلب كلمات مرور أو معلومات حساسة ضمن الملاحظات.
